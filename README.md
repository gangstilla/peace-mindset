# Peace Mindset

A single-page site about everyday calm: a guided breathing circle, six practices, a day in three pauses, an inner-weather check-in and writing prompts.

Live site: https://gangstilla.github.io/peace-mindset/

Static HTML with no build step. Open `index.html` in a browser to preview it locally. GitHub Pages serves it straight from the repo root.

Sister site: [Trading Mindset](https://gangstilla.github.io/trading-mindset/)
